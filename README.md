# Magic: The Gathering Rules Quiz

This project is a quiz application designed to test your knowledge of Magic: The Gathering rules. It uses ChatGPT to provide interactive and engaging questions.

## Features
- Interactive quiz format
- Questions based on official Magic: The Gathering rules
- Powered by ChatGPT for dynamic question generation

## Requirements
To run this project, you need:
- Python 3.8 or higher
- Dependencies listed in `requirements.txt`

## How to Run
1. Clone this repository.
2. Install the required dependencies using `pip install -r requirements.txt`.
3. Run the application with `python mtg_rules_quiz_with_chatgpt.py`.

## Tests
Unit tests are available in the `tests/` directory. Run them with:
```
python -m unittest discover tests
```
